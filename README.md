# OpenGL-Learning-Character-Animation

This is Knight VS Zombie 3D Game, built for learning OpenGL Skeleton animation and Animation Blending topics.

How to control:

  - WASD to control the Knight
  - SPACE or J to Slash the Zombie
  - K to Kick the Zombie
